# NaturalFlow

**Optimizing Speech Flow in Simultaneous Speech-to-Speech Translation**

Audio demo page for NaturalFlow — a fluency-aware framework that reduces unnatural
inter-chunk pauses in simultaneous speech-to-speech translation while preserving
translation quality and latency.

🔊 **Demo:** https://naturalflows2st.github.io/naturalflow/

## Local preview

```bash
python3 -m http.server 8000
# open http://localhost:8000
```

## Structure

- `index.html` — demo page
- `static/` — styles, audio samples, and images
